# 基金信息查询工具（AIFundTool）

输入一串基金代码，图形界面（浏览器）展示每只基金的：

| 字段 | 数据来源 | 更新频率 |
|---|---|---|
| 基金名称/类型 | 天天基金移动端接口 `FundMNBasicInformation` | 每日 |
| 基金经理（含任职区间、任职回报） | 天天基金 `FundMNMangerList` | 每日 |
| **基金经理持有本基金份额（区间）** | 基金**中报/年报** PDF 的"基金份额持有人信息"章节 | 一年最多两次（中报 8 月底前、年报次年 3 月底前） |
| **持有份额较上期变化** | 当期与上一份中报/年报的档位对比（↑N档 / ↓N档 / →持平） | 随持有份额 |
| 基金规模（期末净资产、份额） | `FundMNBasicInformation` 的 `ENDNAV`/`FEGM` | 每季披露后更新 |

附赠展示：净值与涨跌、风险等级、成立日期、申购状态、重仓股票、收益指标、公司从业人员合计持有份额等；**净资产低于 0.5 亿的迷你基金**会在表格中红色高亮并汇总提示清盘风险。

## 分组与本地保存

- **分组输入**：侧边栏每个分组有独立的代码输入框，可「＋添加分组」「重命名」「↑/↓ 排序」「🗑删除」；查询结果按分组分**标签页**展示，每组有自己的总览表、详情和 CSV 导出。**近一年基金经理有变更**（新任/离任）的基金，基金经理单元格琥珀色高亮并在顶部汇总提醒。每组总览表下方还有「**本组经理汇总**」：本组各位基金经理的公司、本组持有几只、现任基金数、在管总规模、从业年限、现任最佳回报（来自经理目录快照，同名经理按现任代码精确区分，支持点表头排序与 CSV 导出）；汇总下方的**经理按钮**可下钻查看该经理的**全部在管基金**——与「单只/经理查询」同款视图（逐基金含经理持有份额/持有较上期，点表头排序，点基金看详情）。
- **单只基金查询**：页面顶部输入 **6 位代码、基金名称关键词或基金经理姓名**，**按回车**或点「🔍 查询」即查；经理姓名支持**一次输入多位**（空格/逗号分隔），每位经理分块展示在管基金总览（与分组查询同款列：名称/类型/规模/**基金经理持有本基金/持有较上期**，支持高亮与**点击表头排序**——规模按数值、持有区间按档位、较上期按升降档，CSV 按当前显示顺序导出，点击基金直接看详情）；**同名经理自动提示**并按所属公司区分。查询历史自动保存在 `查询历史.json`（最多 30 条），点击历史条目可直接再查。
- **本地保存**：分组名称与代码自动保存在项目根目录的 `我的基金.json`，下次启动工具时自动恢复——直接点「开始查询」即可出结果。该文件不受清空缓存影响，可手动编辑或备份。

## 使用方法

### 方式一：双击启动（推荐）

双击 `启动基金工具.bat`，浏览器会自动打开 `http://localhost:8501`。
首次运行会自动安装依赖（需要已安装 Python 3.10+ 和 Node.js）。

### 方式二：命令行

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

在左侧「分组查询」页面输入基金代码（换行/逗号/空格分隔均可），点击"开始查询"；单只基金/基金经理查询在侧边栏切换到「单只 / 经理查询」页面；宏观指标在「🌏 宏观指标」页面。

## 宏观指标页

侧边栏「🌏 宏观指标」三个标签页（数据来自中证指数官网与东方财富公开接口，本地缓存 6~12 小时）：

- **⚖️ 股债性价比**：股债性价比 = 指数盈利收益率(1÷PE) − 中国10年期国债收益率。沪深300、中证500、中证800、中证1000、中证全指五只指数的 PE、盈利收益率、性价比与历史分位汇总表；单指数历史折线图（可选全部/近10年/近5年窗口，附均值与 ±1σ 参考线，可开关叠加指数点位右轴）。分位 ≥80% 提示"股票明显占优"、≤20% 提示"债券明显占优"。另有**股息率口径**：滚动12个月股息率 − 10年期国债收益率（股息率由中证官网全收益指数与价格指数的比值推导，如沪深300 全收益 H00300 vs 000300），为正说明仅分红收益已高于国债。
- **💰 利率与汇率**：中国10年/30年期国债、期限利差(10Y−2Y)、美国10年期国债（均含较一个月前变化）、中美10年期利差、美元兑离岸人民币现价；中美国债收益率近5年走势对比图。
- **📈 增长·通胀·流动性**：GDP累计同比、CPI/PPI同比、制造业PMI、M2/M1同比指标卡（含较上期变化）+ 最近18个月明细表。

## 目录结构

```
app.py                     # 多页应用入口（页面配置 + 侧边栏导航）
ui/
  ├── constants.py         # 全局常量：路径、查询节奏、提醒阈值（调参数只看这里）
  ├── state.py             # 会话状态键集中定义（KEY_*）+ 本地持久化（我的基金/查询历史）
  ├── query.py             # 查询与数据整形：原始行契约 fund_overview_row、经理目录聚合
  ├── render.py            # 渲染层：display_row 展示格式化、详情/分组/经理视图、高亮
  ├── sortable_table.py    # 可点表头排序的表格组件（显式排序键，纯函数生成 HTML）
  ├── page_groups.py       # 📚 分组查询页（批量查询、分组标签页、CSV 导出）
  ├── page_single.py       # 🔍 单只/经理查询页（代码/名称/经理姓名、查询历史）
  └── page_macro.py        # 🌏 宏观指标页（股债性价比/利率汇率/增长通胀流动性）
fundtool/
  ├── client.py            # 天天基金接口客户端（限速、重试）
  ├── macro.py             # 宏观数据客户端（国债收益率、中证指数估值、CPI/PPI/PMI/GDP/M2、汇率）+ 纯函数（ERP、分位）
  ├── holdings.py          # 定期报告基金经理持有份额解析（纯解析 + 缓存管线）
  ├── cache.py             # JSON 文件缓存（带 TTL）
  ├── jschallenge.py       # pdf.dfcfw.com JS 反爬挑战求解（调用 Node）
  └── solve_challenge.js   # Node 挑战脚本执行器
tests/
  ├── test_app.py          # 端到端冒烟测试（AppTest，场景互相独立，需联网）
  ├── test_macro.py        # 宏观数据层纯函数单测（离线）
  ├── test_holdings_parser.py  # 报告解析器单测（离线，含真实报告文本夹具）
  └── fixtures/            # 从真实中报 PDF 提取的“持有人信息”章节文本窗口
我的基金.json               # 分组与基金代码（自动保存，可备份）
查询历史.json               # 单只查询历史（自动保存，不入版本库）
.cache/                    # 运行时缓存（可随时删除）
启动基金工具.bat             # 双击启动（浏览器自动打开 8501）
停止基金工具.bat             # 双击停止 8501 端口上的后台服务
```

分层约定：`fundtool/` 是纯数据层（不依赖 streamlit）；`ui/` 按关注点分为
常量（constants）→ 状态与持久化（state）→ 查询与数据整形（query）→ 渲染（render），
依赖方向单向。数据行的数值字段保留原始类型（`nav_yuan` 为 float、`small` 为 bool），
所有展示文案（`204.16亿 ⚠️`、`>100万份`、`↑2档`）统一由 `render.display_row` 格式化，
排序键也从原始字段计算——不再从展示文本里反向提取数字。

## 关键实现说明

1. **基本信息**：`fundmobapi.eastmoney.com` 移动端 JSON 接口，无需登录，一个请求拿齐名称/经理/规模。
2. **按基金经理姓名查询**：天天基金没有按姓名搜经理的接口，改为经 `FundDataPortfolio_Interface.aspx`（经理排行榜数据源）全量拉取约 4300 位经理目录（每人含现任基金代码列表），本地按 姓名>前缀>包含 分级匹配；目录缓存 7 天。
2. **基金经理持有份额**（本项目最复杂的部分）：
   - `api.fund.eastmoney.com/f10/JJGG?type=3` 拿定期报告公告列表；
   - `np-cnotice-fund.eastmoney.com/api/content/ann` 拿 PDF 附件地址；
   - 下载 PDF 时 `pdf.dfcfw.com` 会返回 JS 反爬挑战，用 Node 执行挑战脚本算出 Cookie 后重试；
   - `pdfplumber` 定位"从业人员持有本基金"章节，提取"本基金基金经理持有本开放式基金"行的区间（如 `>100`，单位万份）；
   - **A/C 等多份额级别的基金**：按查询代码所属级别（基金简称末尾字母）取对应行，不再用合计——经理只在 C 类持有时，A 类代码不会显示合计值；详情页附各份额级别明细。
   - 解析结果按公告 ID+份额级别 **永久缓存**（报告内容不会变），按基金代码 7 天刷新指向最新报告。
3. **限速**：所有请求间隔 ≥0.25 秒，避免触发风控。

## 常见问题

- **经理持有份额显示 `--`**：新基金可能还没有中报/年报；解析失败的行会在详情里展示报告原文摘录，也可点报告 PDF 链接人工核对。
- **接口失效**：非官方接口，若字段/地址变化，集中修改 `fundtool/client.py` 即可。
- **缓存问题**：删除 `.cache/` 目录即可全部重新拉取。
